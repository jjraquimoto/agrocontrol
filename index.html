Dados e segurança

Sincronização automática

As alterações são enviadas quando há internet. Se algo ficar pendente, o AgroControl avisa sem interromper seu trabalho.

No modo conectado, os registros ficam em uma fazenda privada no Supabase, com cópia local para edições sem internet. Na demonstração, ficam apenas neste navegador.

Exporte um backup JSON regularmente. Ao trabalhar offline, volte a conectar para sincronizar e confira o indicador de status. Em caso de conflito, os dados locais ficam preservados e é necessária revisão manual.

Acesso offline neste aparelho

Após entrar online e carregar uma fazenda, cadastre uma senha local para abrir seus dados mesmo quando o SDK não puder ser carregado. Ative o cofre local AES-256-GCM para proteger os registros salvos neste aparelho. Guarde a senha: ela não pode ser recuperada e, sem ela, dados offline pendentes poderão ser perdidos.

A restauração substitui os dados atuais após confirmação. Aceita backups AgroControl 3.0/4.0 e tenta importar os formatos locais anteriores; não substitui validação humana de registros antigos.

Integridade e instruções

Como começar

1. Cadastre lotes (opcional). 2. Cadastre cada animal em Rebanho. 3. Selecione animais nos módulos Sanidade, Produção e Movimentações. 4. Consulte os históricos individuais. 5. Exporte backups frequentemente.

Limites desta versão

A versão conectada exige configurar Supabase, permissões e políticas SQL. A sincronização usa revisão por fazenda e bloqueia sobrescrita em caso de conflitos. Antes de vender, são necessários testes de carga, recuperação de backups e auditoria mais completa.
