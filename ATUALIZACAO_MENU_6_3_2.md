# Atualização 6.3.2 — compatibilidade entre aparelhos

A versão 6.3.1 corrigiu o tamanho do texto do menu Mais. Esta versão amplia as regras de responsividade para navegadores e WebViews com diferentes tamanhos de tela.

Alterações limitadas a CSS/JS de navegação, identificação da versão e atualização de cache estático. O backend, a sincronização e o cofre offline não foram modificados.

A correção é preventiva para diferentes tamanhos e configurações de fonte. O problema específico relatado no segundo aparelho ainda precisa de captura de tela para confirmação.
